## 🌏 English

An **ESP32-P4 board as a real USB keyboard + mouse** for Windows: one JSON job =
screenshot → decide → act → verify. No driver, no injection, no cooperation needed
from the target application.

| Repo | What it is |
|---|---|
| [`esp32p4-hid-agent`](https://github.com/BSGGPRO/esp32p4-hid-agent) | Hardware-level input for Windows: real HID, zero driver, zero injection. |
| [`itchio`](https://github.com/BSGGPRO/itchio) | itch.io game downloader, launcher and local/LAN server. Tools only, no game content. |
| [`itchio-ios-webview-shell`](https://github.com/BSGGPRO/itchio-ios-webview-shell) | Wrap a Unity WebGL game into an iOS app shell. Shell only, no game content. |
