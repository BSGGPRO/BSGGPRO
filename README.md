**在做的 / What I build**

- [itchio-ios-webview-shell](https://github.com/BSGGPRO/itchio-ios-webview-shell) — 把 Unity WebGL 游戏套成 iOS App 的壳，本地 HTTP + WKWebView，GitHub Actions 出未签名 IPA。

**English**

An ESP32-P4 board as a real USB keyboard + mouse for Windows: one JSON job = screenshot → decide → act → verify. No driver, no injection, no cooperation from the target app.

- [`esp32p4-hid-agent`](https://github.com/BSGGPRO/esp32p4-hid-agent) — hardware-level input, zero driver, zero injection.
- [`itchio`](https://github.com/BSGGPRO/itchio) — itch.io game downloader, launcher and local/LAN server. Tools only, no game content.
- [`itchio-ios-webview-shell`](https://github.com/BSGGPRO/itchio-ios-webview-shell) — wrap a Unity WebGL game into an iOS app shell.
